## 🌟 Key Features & Capabilities

### 1. 📝 Official Pattern Mock Test Engine (32+ Exam Patterns)
- **B.Tech (MAKAUT / University Autonomous)**: 70-Mark End-Semester papers (Group A 10×1M MCQ, Group B 3×5M Short, Group C 3×15M Long).
- **SSC CGL (Tier-1)**: 200-Mark CBT simulation (General Intelligence, GA, Quantitative Aptitude, English Comprehension) with +2 / -0.5 marking.
- **NTA JEE Main**: 300-Mark official pattern (Physics, Chemistry, Mathematics with Section A MCQs and Section B Numerical Integer inputs).
- **GATE 2027**: 100-Mark IIT Madras pattern (15M General Aptitude, 13M Engineering Mathematics, 72M Technical) with negative marking (-1/3 & -2/3).
- **BCA / MCA Semester**: 70-Mark university patterns with Python programming, data structures, and relational database schemas.
- **CBSE Class 10 & 12**: 80-Mark board model papers with official step-by-step marking rubrics.

### 2. 📸 24/7 AI Instant Doubt Solver & OCR
- **Photo OCR & Formula Input**: Upload question snapshots or type complex mathematical equations.
- **Academic Derivation Structure**: Concept identification, step-by-step mathematical proof, common exam traps to avoid, and related PYQs.

### 3. 🏆 All-India Test Series (AITS) & National Leaderboard
- National live scheduled mock championships.
- Real-time All-India Rank (AIR) forecasting, percentile computation, and question-level speed analytics.

### 4. 🗂️ Anki-Style Active Recall Flashcard Studio
- 3D spatial flip cards powered by **Framer Motion**.
- SM-2 Spaced Repetition memory rating algorithm (*Again, Hard, Good, Easy*).

### 5. 📄 Smart PDF Viewer & AI Socratic Annotator
- In-app study note viewer synced with Google Drive semester archives.
- Highlight any equation or definition to trigger instant AI explanation and exam tips.

### 6. 🎯 AI Weakness Diagnostic Radar
- Chapter-level health diagnostic heatmap (🟢 Strong $\ge 80\%$, 🟡 Moderate $60-79\%$, 🔴 Critical Gap $<60\%$).
- 1-Click *"Launch 10-Q Fix Drill"* remediation papers.

### 7. 🎙️ AI Viva Voice Examiner
- Speech-enabled college lab viva simulator with real-time academic grading and counter-questioning.

### 8. ⏱️ 432Hz Pomodoro Focus Room
- 25-minute uninterrupted study sprints with built-in 432Hz alpha wave soundscapes.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher)
- npm / pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/aryanshaw421-alt/VIDYA-AI.git

# Navigate to project directory
cd VIDYA-AI

# Install dependencies
npm install

# Start the Vite development server
npm run dev
```

### Build for Production
```bash
npm run build
```
